# Theorrem Website Instructions

## Project
This is the official Theorrem website deployed through Vercel.

## Brand
- Preserve the existing Theorrem website theme.
- Primary blue must come from the current website styles.
- Use the existing typography, header, footer, spacing and button patterns.
- The design should remain light, clean, premium and product-led.
- Avoid generic dashboard-heavy SaaS design.
- Avoid excessive gradients, shadows and decorative cards.

## Implementation
- Inspect existing components and styles before creating anything new.
- Reuse shared components wherever appropriate.
- Do not break existing pages.
- Maintain desktop, tablet and mobile responsiveness.
- Do not leave dead buttons or placeholder interactions.
- Run the project and production build after meaningful changes.
- Fix all console and build errors before completing a task.

## Document Extraction Page
- Keep the approved hero section unless explicitly instructed otherwise.
- Product sections should be screenshot-driven and editorial.
- Workflows should be implemented as native frontend animations rather than embedded competitor recordings.
- Use competitor references for close structural inspiration, but use original Theorrem branding, copy and interface content.
- The interactive product demo should remain separate from the marketing journey.
