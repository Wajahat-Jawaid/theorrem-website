# Auren AI Landing Page

A clean, light-themed AI agents agency landing page inspired by modern enterprise SaaS layouts.

## Files

- `index.html`
- `styles.css`
- `script.js`

## How to use

Copy these files into your repo and open `index.html`, or deploy the folder to Vercel/Netlify/static hosting.

## Quick edits

Search and replace:

- `Auren AI` — your brand name
- `hello@aurenai.com` — your email
- Hero headline and section copy as needed

## Notes

This is not a 1:1 clone of any live site. It uses original copy, original layout components, and no copied brand assets.
